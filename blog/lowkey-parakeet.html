Lowkey Parakeet: voice to text, on the device

Workshop42 project notesLocal review draft

TypeVoice to text
Model executionOn the device
StackTauri / Rust / React
NotesLocal review draft

Speech, processed locally

Lowkey Parakeet is my voice-to-text project built around NVIDIA Parakeet speech models. Its focus is local transcription: running the speech model on the device rather than sending audio to a cloud transcription service.

The application around the model

The project uses Tauri, Rust and React, with desktop and mobile targets spanning Windows, macOS, Linux and Android.

The interesting part for this workshop is the combination of application development and local model execution. The speech model is one part of the build; the interface and the application around it are part of the work too.

A different kind of build

Software adds another material to the workshop: an idea can become a tool without becoming a printed object.
