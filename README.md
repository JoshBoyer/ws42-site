# Workshop42

Static maker journal at https://ws42.ca/.

Use Node.js22. No package installation is required.

- npm run dev: local preview on127.0.0.1:4242
- npm run build: stage the public-only .site directory
- npm run check: verify navigation, preserved content, themes, motion, video policy, ranges and artifact safety

GitHub Pages deploys .site from main through the existing Pages environment. Raw source photos, test captures and local working notes are excluded from the website. Published photos have source metadata removed.
