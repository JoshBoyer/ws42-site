Nexus: learning through AI orchestration

Learning by building an AI system

Nexus is my independent AI orchestration project: software for working with the pieces of an AI system together. It's also a place for me to learn how those pieces fit by building them, examining the result and refining the next iteration.

The project gives me a practical way to explore questions that are hard to answer from a diagram alone, from what belongs in the interface to what the underlying service needs to manage.

Separating the interface from the system

The project brings together a React and TypeScript interface, Node.js services and PostgreSQL. The web interface is the place to work with the system; the underlying service owns the system's state and execution. Keeping those roles distinct makes the boundary as interesting as the individual screens.

A workshop project in progress

Nexus is independent work in progress, not a claim that every planned capability is deployed. Like a physical prototype, it gives me a way to test an approach, see where it holds up and carry what I learn into the next build.
